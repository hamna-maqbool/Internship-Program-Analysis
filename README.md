
# 📊 Internship Program Analysis

## 🎯 Objective
Analyze and visualize internship completion rates 
to identify key success factors.

## 📁 Dataset
- 1000+ internship records (custom dataset)
- Columns: Department, Duration, Mentor Assigned,
  Tasks Completed, Attendance, Status

## 🔍 Key Findings
- Overall completion rate: **66.3%**
- Operations dept has highest completion: **71%**
- 6-month programs perform best: **73.9%**
- Interns with mentors complete **10% more**
- Paid internships show higher completion: **69.8%**

## 📊 Visualizations
- Pie Chart — Overall completion status
- Bar Chart — Completion rate by department
- Grouped Bar — Completion by duration
- Stacked Bar — Mentor impact
- Stacked Bar — Stipend impact
